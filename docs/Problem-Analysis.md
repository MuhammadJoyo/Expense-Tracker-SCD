# Problem Analysis
## Project
Expense Tracker - Personal Finance Management System
## Problem
People often record daily expenses manually, making it difficult to monitor spending, categorize transactions and calculate total expenses.
## Proposed Solution
A Java desktop application that allows users to add, view, edit, delete, search and filter expenses.
## Computing Challenges
- Validating user input
- Managing expense records
- Maintaining persistent storage
- Calculating totals efficiently
- Preventing invalid records
- Protecting shared data during concurrent access
## Scope
The current application is a local desktop expense tracker. It does not currently provide cloud synchronization or multi-user networking.
