# Project Proposal
## Title
Expense Tracker - Personal Finance Management System
## Objective
To develop a Java-based desktop application for managing personal expenses.
## Main Features
1. Add expenses.
2. View transaction history.
3. Edit expenses.
4. Delete expenses.
5. Search transactions.
6. Filter by category.
7. Calculate total expenses.
8. Store expense records in a local file.
## Technology Stack
- Java 17+
- Java Swing
- Maven
- JUnit 5
- Git and GitHub
- File-based CSV storage
## Expected Outcome
A functional desktop application demonstrating object-oriented programming, data structures, file handling, GUI development and software testing.
